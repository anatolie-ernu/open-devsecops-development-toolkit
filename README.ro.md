# Open DevSecOps Development Toolkit

Toolkit public open-source, branded **ERNU.EU**, pentru calitatea codului,
securitate, conformitatea licențelor și review în GitHub. Conținutul este
complet depersonalizat.

**SonarQube Community + Semgrep CE + MegaLinter + Trivy + Gitleaks +
Reviewdog** reprezintă baza. Se adaugă **ORT** pentru compliance și
**PR-Agent + Ollama** pentru review AI self-hosted.
